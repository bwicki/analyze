# Design-Boards (Phase 0, Claude Design)

Zehn Boards im Format `.dc.html` plus `canvas.json` (Anordnung): Start/Kennung, die fünf Phasen,
Profil-Assistent, Meine Fahrten, Fahrtbericht A4, Handy-Ansicht. Karte und Höhenprofil darin sind aus den
echten GB26-Daten gerechnet; Bilder liegen als Assets im Claude-Artefakt und werden hier nicht mitgeliefert
(die Boards zeigen an diesen Stellen leere Bildrahmen). Massgeblich für den Look & Feel ist `css/app.css`.
